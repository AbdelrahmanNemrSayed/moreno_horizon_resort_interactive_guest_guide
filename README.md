# Moreno Horizon Spa & Resort - Interactive Guest Guide & 3D Map
### الدليل التفاعلي الذكي الشامل وخريطة المنتجع ثلاثية الأبعاد • الغردقة (Hurghada, Red Sea, Egypt)

موقع وتطبيق ويب تقدمي (PWA) فندقي تفاعلي متكامل لنزلاء منتجع وسبا **مورينو هورايزون الغردقة**.

---

## 🌟 أبرز المميزات (Key Features)

- **🗺️ خريطة المنتجع التفاعلية ثلاثية الأبعاد (3D Interactive Resort Map):**
  - معاينة كاملة لجميع مرافق المنتجع (المسابح، الشاطئ، المطاعم، مركز الغوص، السبا، الملاعب، والمباني السكنية).
  - تحكم متقدم بالكاميرا: بوصلة اتجاه الشمال الحركية، التدوير الدقيق، إمالة المنظور ثلاثي الأبعاد (3D Tilt / Pitch).
  - تبديل طبقات الخريطة (قمر صناعي نهاري، قمر صناعي ليلي، رسم توضيحي للمنتجع).
  - جولة طيران جوي فضائي ذاتية 360° حول المنتجع (Autonomous 360° Orbit Flyover Tour).

- **🚶‍♂️ نظام الملاحة الحية التفاعلية ومحدد الغرف (Live Wayfinding & Turn-by-Turn Navigation):**
  - تحديد موقع أي غرفة فندقية برقم الغرفة ومعرفة المبنى والطابق بدقة.
  - رسم مسار السير المباشر المضاء مع حساب المسافة بالأمتار وزمن المشي بالدقائق.
  - **محاكاة السير الحي (Live Walking Simulation):** مؤشر نزيل متحرك على مسار الممشى الفعلي مع كاميرا تتبع ذكية سلسة 60fps.
  - توجيه خطوة بخطوة متزامن مع المعالم، مع مسار ميسر مخصص للكراسي المتحركة وعربات الأطفال (♿ Accessible Step-Free Pathway).
  - بطاقة معاينة مرافق منبثقة متجاوبة بالكامل لجميع شاشات الهواتف المحمولة.

- **📖 دليل الخدمات والمطاعم الشامل (Comprehensive Directory & Digital Menus):**
  - قوائم طعام رقمية تفاعلية للمطاعم والبارات مع التصفية والأسعار وساعات العمل.
  - دليل الأنشطة اليومية، مواعيد الرحلات البحرية والغطس، وبرامج الترفيه.
  - حجز طاولات المطاعم وطلب خدمات الغرف الفورية.

- **🌐 دعم متعدد اللغات (Multilingual Support):**
  - العربية (Arabic) 🇪🇬
  - الإنجليزية (English) 🇬🇧
  - الروسية (Russian) 🇷🇺
  - الألمانية (German) 🇩🇪

- **📱 تطبيق ويب تقدمي متكامل (PWA & Offline Ready):**
  - يدعم التثبيت المباشر على الشاشة الرئيسية للهواتف (Android & iOS).
  - تخزين مؤقت للعمل دون اتصال بالإنترنت عبر Service Worker متطور.

---

## 🚀 تشغيل المشروع محلياً (Local Setup)

لا يتطلب المشروع أي بيئة تشغيل معقدة، ويعمل مباشرة عبر أي خادم ويب ثابت (Static Web Server):

```bash
# تشغيل خادم محلي باستخدام Node.js
node server.js
```

أو عبر فتح `index.html` مباشرة في أي متصفح حديث.

## 📂 بنية المشروع (Project Structure)

```text

├── moreno_resort_map_new.png      # الخريطة الأساسية المصورة للمنتجع
├── css/
│   └── style.css                  # التنسيقات ونظام التصميم المخصص
├── js/
│   ├── data.js                    # قواعد بيانات المرافق، الغرف، القوائم، والترجمات
│   ├── map-engine.js              # محرك الخريطة ثلاثية الأبعاد والملاحة الحية
│   ├── wayfinder.js               # محرك البحث عن الغرف وحساب المسارات
│   ├── app.js                     # منطق التطبيق والواجهة التفاعلية
│   └── virtual-resort-map.js      # محرك الخريطة الافتراضية التوضيحية
└── assets/
    ├── icons/                     # أيقونات التطبيق و PWA
    └── images/                    # صور المرافق والمطاعم والشاطئ
```
