# Moreno Horizon Resort - Architectural Rules & Invariants

These rules govern code structure, cache invalidation, and server state management across the Moreno Horizon Guest Guide codebase.

## 1. Unified Build & Cache Invalidation Rule
* **Invariant:** All asset versions and cache names MUST remain strictly synchronized across `sw.js`, `index.html`, and `admin.html`.
* **Central Source of Truth:** `config/version.json` defines `cacheVersion` (e.g. `57.0`) and `appVersion`.
* **Build Protocol:**
  * Whenever making updates to frontend assets, CSS, data, or scripts, always execute the full build command:
    ```bash
    npm run build
    ```
  * `npm run build` runs `npm run sync:version`, `npm run build:locales`, and `npm run build:data` in sequence.
  * **Never manually modify query parameter versions (`?v=...`)** in `index.html`, `admin.html`, or `sw.js`. Always update `config/version.json` and let `scripts/sync-version.js` propagate the version.

## 2. Server State Persistence Invariant
* **Invariant:** Any operational resort state (e.g., beach flag warning level, active live announcements, dynamic emergency contacts/WhatsApp, POI open/closed statuses, hotspot captive portal URL) managed by administrators in `server.js` MUST be persisted to disk.
* **Storage Path:** `config/resort-state.json`.
* **Execution Flow:**
  1. On server startup, state is restored from `config/resort-state.json` via `loadResortState()`.
  2. Whenever an admin mutation endpoint (e.g., `/api/admin/resort/*`) receives an update, it must immediately call `saveResortState()` before broadcasting the change via Server-Sent Events (`broadcastToSseClients()`).
  3. Never store persistent operational configuration exclusively in in-memory variables.

## 3. Data & Modular Architecture Integrity
* **Invariant:** Source data lives in `src/data/*` and source locales in `locales/*.json`.
* `js/data.js` and `js/locales-bundle.js` are compiled distribution bundles generated by `scripts/build-data.js` and `scripts/build-locales.js`.
* Always run `npm run validate` to verify key count symmetry across all 4 locales (AR, EN, RU, DE) and coordinate accuracy.
